Getting started

Open this file in Google Chrome or Microsoft Edge (Safari and Firefox can't use USB serial). Plug the tinySA Ultra in by USB, switch it on, click Connect tinySA and pick the port (it usually shows as "tinySA" or "STM32 Virtual ComPort"). If no port appears, tick Show all serial ports and try again. Choose a preset or type a range, then Start scan. Let it run several sweeps (walk the stage, wait for the room to fill) so Max hold catches intermittent signals.

Good settings for wireless mics

Step 25 kHz with RBW 30 kHz is a good balance. Finer step / smaller RBW shows more detail but sweeps slower. Leave attenuation at 0 dB unless you're right next to strong transmitters. LNA on gives a lower noise floor on the Ultra. The tinySA sweeps about 450 points at a time, so wide scans are done in chunks — the blue bar under the graph shows progress. Above about 800 MHz the Ultra needs its Ultra mode enabled on the device.

Using the scan in your coordination software

Shure Wireless Workbench — click Shure WWB, then in WWB's Frequency Coordination area import the file as scan data.
Sennheiser WSM — click Sennheiser WSM; the file uses WSM's scan layout (kHz, semicolons, range header). Import it in Professional Setup as scan data.
Other apps (IAS, Wavetool, Soundbase Coord, RF Venue etc.) — use Generic CSV. If an app refuses a file, try Custom with a different unit / separator / header.
Open freqs list exports the centre of every open gap (one MHz value per line) for importing as a frequency or inclusion list. Carriers list exports detected signals for exclusion lists.

Mouse

Drag across the graph to zoom, scroll wheel to zoom around the cursor, double-click to reset. Click a row in the tables to jump to it. Click legend items to hide/show traces. Space bar starts/stops a scan.
